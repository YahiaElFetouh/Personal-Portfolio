# Yahia El Fetouh — Personal Portfolio

A responsive personal portfolio featuring professional experience, selected projects, and contact information.

## View locally

Download the repository, keeping the `images/` folder beside `index.html`, and open `index.html` in a browser. No installation or build step is required. An internet connection loads Bootstrap 5 from its official CDN.

## Built with

- HTML and custom CSS
- Bootstrap 5
- Native disclosure controls for project contributions

## Customize

Edit `index.html` to update text, project links, colors, and layout. The portrait and employer logos live in `images/`. Keep these files with the HTML when deploying or viewing locally.

## Content and assets

Professional information and portrait belong to Yahia El Fetouh. Organization logos identify previous employers and remain the property of their respective owners. Project entries describe individual contributions to collaborative work where applicable.


## Hosting and social previews

Live site: https://yahiaelfetouh.github.io/Personal-Portfolio/

GitHub Pages serves the repository root. No build step is required. Canonical, Open Graph and Twitter card metadata use the live HTTPS URL. The 1200 × 630 PNG at `images/portfolio-preview.png` is the social preview card. When updating it, refresh the site in [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/).
